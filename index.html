시작하기Get started

세 걸음이면 끝Three steps

1APK 받기Get the APK

깃허브 릴리스에서 최신 APK를 받아 설치합니다. 「유해한 앱」 경고가 뜨면 「세부정보 → 무시하고 설치」를 누르세요. 새 판은 노리 안의 「업데이트 확인」으로 받습니다.Download the latest APK from GitHub Releases. If Android warns about a harmful app, tap "More details → Install anyway". Later versions come through "Check for updates" inside Nori.

2롬 폴더 고르기Pick your ROM folder

ps2, psp, snes처럼 기기 이름으로 나눈 폴더의 상위 폴더 하나를 고릅니다. ES-DE 폴더가 있으면 함께 고르세요.Choose the parent folder of your system folders (ps2, psp, snes…). Add your ES-DE folder if you have one.

3에뮬레이터 정하기Set up emulators

기기 고르는 화면에서 X를 눌러 그 기기를 열 에뮬레이터를 고릅니다. 빈 그림은 설정에서 한 번에 받습니다.On the system screen, press X to choose the emulator for that system. Fill missing art from Settings in one go.

FAQ

자주 묻는 질문Questions

무료인가요?Is Nori free?

베타 동안은 무료입니다. 1.0 정식판부터는 한 번 결제하면 계속 새 판을 받는 방식이 될 예정입니다.Yes, during the beta. From 1.0 it becomes a one-time purchase that includes future updates.

게임이나 에뮬레이터가 들어 있나요?Does it include games or emulators?

아니요. 노리는 런처라서 게임 파일과 에뮬레이터는 들어 있지 않습니다. 직접 가진 게임으로만 써 주세요.No. Nori is a launcher, so no games or emulators are included. Please only use games you own.

ES-DE에서 쓰던 그림을 쓸 수 있나요?Can I reuse my ES-DE media?

네. ES-DE 폴더를 고르면 downloaded_media의 그림·영상과 gamelists의 이름·설명·장르를 그대로 읽습니다.Yes. Pick your ES-DE folder and Nori reads the media in downloaded_media plus names, descriptions and genres from gamelists.

파일 이름을 한글로 바꾼 롬도 그림을 받을 수 있나요?Can renamed ROMs get art?

네. 게임 창(X) → 그림·영상 관리 → 검색해서 그림 받기에서 원래 영어·일본어 이름으로 찾으면 됩니다. 자동으로 받을 때도 이름으로 못 찾으면 파일 지문(CRC·MD5)으로 한 번 더 찾습니다.Yes. In the game window (X) → Manage media → Search and download art, search by the original title. Automatic scraping also retries with the file's CRC and MD5.

휴대폰에서도 되나요?Does it work on phones?

됩니다. 가로 화면에 맞췄고 손가락으로도 쓸 수 있지만, 패드가 달린 기기에서 가장 편합니다.Yes. It's designed for landscape and works with touch, but it's best on devices with built-in controls.

버그는 어디에 알리나요?Where do I report bugs?

깃허브 이슈의 「버그 제보」 양식에 남겨 주세요. 질문과 건의는 깃허브 토론에 남기면 됩니다.Use the bug report form in GitHub Issues. Questions and ideas go to GitHub Discussions.
